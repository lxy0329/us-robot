# DS323 · 小禾家务助手

根据 [Figma 手机原型](https://www.figma.com/design/7hNnuM4zI4mjhuvTxqI3s1?node-id=137-683) 制作的单文件 HTML 演示。下载 `index.html` 后用浏览器打开，桌面和手机均使用统一的手机布局。

## 演示功能

- 地图、对话、任务和设置四个页面，统一字号、间距和固定底部导航。
- 中间机器人入口轻点新建对话，长按开始语音输入；发送明确的家务指令后创建对应任务。
- 新建及更新的任务靠前展示；最近对话直接展示，较早记录按项目或归档查看。
- 对话可补充执行要求、预约时间、暂停或继续任务；任务页创建的任务也会生成关联对话。
- 对话菜单支持重命名、分享和删除；右侧历史刻度仅记录用户消息，首次点击预览，再次点击定位。
- 包含长期使用的家务示例记录，以及洗衣、收纳、玩具、餐食等场景的本地演示回复。

示例回复由本地规则生成，任务状态为演示数据，未连接真实机器人或远程 AI。记录保存在当前浏览器本地存储，组员之间不会自动同步聊天或任务。地图实景模型需要联网。语音识别取决于浏览器支持和麦克风权限，手机上请通过 HTTPS 页面使用。

## 协作

1. 仓库所有者可在 **Settings → Collaborators** 邀请组员。
2. 从 `main` 新建分支，修改 `index.html` 中对应页面。可用中文标题或 `data-screen` 查找页面，脚本位于文件末尾。
3. 在手机宽度下检查修改涉及的入口和返回路径，再开 Pull Request，说明修改了什么和如何验证。
