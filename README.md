# DS323 · 小禾家务助手

根据 [Figma 手机原型](https://www.figma.com/design/7hNnuM4zI4mjhuvTxqI3s1?node-id=137-683) 制作的单文件 HTML 演示。下载 `index.html` 后直接用浏览器打开。样式、交互和素材都在文件内，可以离线预览。

底部导航可切换地图、求助、任务和设置。可以在地图切换 2D / 3D，打开求助列表，或在设置里尝试通知与影像保存选项。原型使用示例数据，部分操作记录在当前浏览器。

## 协作

1. 仓库所有者可在 **Settings → Collaborators** 邀请组员。
2. 从 `main` 新建分支，修改 `index.html` 中对应页面。可用中文标题或 `data-screen` 查找页面，脚本位于文件末尾。
3. 在手机宽度下试点本次改动涉及的入口和返回路径，再开 Pull Request，说明修改了什么和如何验证。
